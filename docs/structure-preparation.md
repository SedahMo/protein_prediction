# 结构准备与编号

输入应为最终表达成熟蛋白的完整序列；信号肽、纯化标签、linker 和 Fc 是否保留须与结构和实验目的保持一致。一个 FASTA 可含多条链，用配置 chains 把每个 PDB 链映射到 FASTA record ID。链内 ATOM 残基顺序必须与 FASTA 完全一致。突变使用 PDB 编号，不是 FASTA 序号、IMGT 或 Kabat 编号；不要未经映射直接套用抗体编号。

优先采用与参考构建体一致的实验结构；预测结构须记录引擎、版本、模板、参数、pLDDT/PAE 和结构文件校验和。pLDDT 是模型局部置信度，不是热力学稳定性。域间 PAE 和 linker 不确定性较高时，单一结构不足以支持稳定性排名。

当前准备模块：拒绝多 MODEL、非标准残基、HETATM、插入编号、alternate location、空链 ID、重复原子、缺失主链原子及 FASTA 不匹配；保留坐标、链和残基编号，复制为 input.pdb。它不补环、不填补侧链、不做质子化，也不能确认结构已达到物理合理性。

人工预处理须逐项记录：

- 选择哪一个模型与 alternate conformer；保留一套坐标后清空 altLoc 标志。
- 插入码如 H100A 的重编号及旧→新映射；本实现要求先解除歧义。
- 缺失残基/侧链的建模方法及局部可信度。RepairPDB 不能替代缺失骨架建模。
- 水、配体、糖基化、离子和其他 HETATM 的去留；对功能/稳定性关键的组分不能为通过检查而盲目删除。当前流程不支持需要这些组分的计算。
- 二硫键连通性、游离 Cys、异常肽键/链断裂、碰撞、侧链完整性及相关结构质量指标；程序的序列匹配并不保证这些检查通过。

保存 `structure-review.md`，包含来源/版本、链域/linker 边界、以上处理、运行条件、已知局限及实验验证计划。若使用多个可信模型，每个模型单独运行并分别报告，以结构编号分组；不要把模型间差异混入同一结构的随机重复 SD。
